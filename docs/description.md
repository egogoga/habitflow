# HabitFlow — описание проекта

## 1. Актуальность
Привычки формируют нашу жизнь, но отслеживать их вручную неудобно.
Существующие приложения перегружены функциями. HabitFlow — минималистичный трекер.

## 2. Цель проекта
Создать веб-приложение, позволяющее пользователю заводить привычки,
отмечать их выполнение и видеть прогресс.

## 3. Целевая аудитория
- Люди 16–45 лет, желающие изменить образ жизни
- Студенты, спортсмены, айтишники

## 4. Функциональные требования
- Регистрация и аутентификация
- CRUD привычек (создать, читать, обновить, удалить)
- Отметка выполнения за день
- Статистика: стрик (серия подряд), процент выполнения
- Категории привычек

## 5. Нефункциональные требования
- Веб-интерфейс, работает в браузере
- Отклик ≤ 300 мс
- Данные пользователей изолированы

## 6. Технологический стек
- Backend: FastAPI
- БД: PostgreSQL
- UI: HTML/CSS/JS
- Развёртывание: Docker

## 7. Архитектура (кратко)
UI → HTTP API → Backend → БД

## 8. План развития
- MVP (см. задание 2)
- Далее: напоминания, экспорт, мобильная версия
